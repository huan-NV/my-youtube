# Tam Linh Căn - Thăng Thiên Lộ

## Mô tả

Truyện tiên hiệp cổ đại kể về Lâm Huyền, một thiếu niên 16 tuổi có tam linh căn (kim, hỏa, mộc) - một tư chất bình thường hiếm hơn tứ, ngũ linh căn trong gia tộc Lâm đang suy tàn. Khi tìm được công pháp cổ xưa phù hợp với tam linh căn, anh bắt đầu con đường tu tiên đầy thử thách để vươn lên và bảo vệ gia tộc.

## Cấu trúc thư mục

```
truyen_moi/
├── chuong/          # Thư mục chứa các chương truyện
├── config.md        # File cấu hình
├── note.txt         # File ghi chú
└── README.md        # File mô tả này
```

## Hướng dẫn sử dụng

1. Đọc file `config.md` để hiểu cài đặt
2. Xem file `note.txt` để biết tiến độ phát triển
3. Các chương truyện được lưu trong thư mục `chuong/`
